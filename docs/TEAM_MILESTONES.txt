OMNICORE CAPSTONE PROJECT: 2-MONTH MILESTONES & TEAM RESPONSIBILITY MATRIX
================================================================================
College Senior Design / Final Year Capstone Project
Project Duration: 8 Weeks (2 Months) | Team Size: 3 Students
Lead Tech Stack: TypeScript, Node.js, Express, React, Vite, Tailwind CSS, Gemini API

--------------------------------------------------------------------------------
1. TEAM MEMBER RESPONSIBILITIES
--------------------------------------------------------------------------------

STUDENT 1 (Core Pipeline & AI Engine):
- Prompt pipeline design & system instruction personas.
- Integration of Google GenAI SDK (gemini-3.8-flash) on server-side.
- Fallback deterministic simulation logic for offline/test environments.
- Multi-turn conversation context window & token budget limits.
- Model performance benchmarking (latency, token efficiency, response quality).

STUDENT 2 (Channel Adapters & Webhook Gateway):
- Inbound normalizers: Slack BlockKit/Event API, Discord interaction webhooks.
- REST API endpoint specifications & contract enforcement.
- Outbound egress formatters (Markdown, Slack Blocks, Discord Embeds).
- Webhook signature verification (HMAC SHA-256) and security sanitization.
- Python and Node.js client SDK libraries for external developers.

STUDENT 3 (Developer Studio & CI/CD Verification Bot):
- Interactive React Developer Portal & multi-channel sandbox UI.
- Action Bot automated integration test suite (/api/v1/test-connection).
- GitHub Actions CI workflows (.github/workflows/ci.yml, bot-verification.yml).
- In-app documentation browser & embed snippet generator.
- Release engineering, packaging, and final capstone demonstration deck.
